# data — 데이터

학습·평가에 쓰는 **데이터 폴더**입니다. 공유 영역이라 바꾸려면 PR과 팀 확인이 필요합니다.

## 담당과 배포
- 데이터 전처리는 **이총(`chong`)** 이 맡습니다. 전처리한 결과를 **구글 드라이브**로 배포하고, 팀원은 받아서 이 폴더에 둡니다. (드라이브 링크: _미정, 정해지면 여기에 적기_)
- 같은 데이터로 학습해야 모델 비교가 의미 있으므로, 받은 데이터의 버전을 이 문서나 `docs/`에 기록합니다.
- **이미지와 라벨은 Git에 올리지 않습니다** (KAMP 데이터 재배포 조건 미확인, `.gitignore`). 링크 공유도 팀원에게만 권한을 주는 비공개로 합니다.

## 데이터를 받아 배치할 때 지켜야 할 것
- 라벨은 YOLO 형식(`class x_center y_center w h`, 0~1 정규화) txt이고 **이미지와 같은 이름**이어야 합니다.
- 이미지 폴더와 라벨 폴더는 **`images/`와 `labels/` 형제 폴더**여야 합니다. 학습 코드가 이미지 경로의 `/images/`를 `/labels/`로 바꿔 라벨을 찾습니다.
- 호기(장비)마다 이미지 해상도가 다르므로 호기 정보를 담은 목록(매니페스트)이 필요합니다. 파일명 앞의 001/002는 호기가 아닙니다.
- 구체적인 폴더 구조와 파일 형식은 팀 합의로 정해 `docs/`에 규약으로 남길 예정입니다.

## 전처리할 때 알아야 할 원본의 특성 (자세한 근거는 [docs/dataset.md](../docs/dataset.md))
- **이미지에 장비가 그린 색 박스(표시)가 이미 찍혀 있습니다.** 지우지 않고 학습하면 모델이 결함이 아니라 표시를 보고 맞힙니다.
- 라벨된 이미지는 **500장**입니다(400장은 `라벨링 6종 세트/images 400`, 100장은 원본 bmp 폴더).
- 모든 이미지가 NG 판정이라 **정상 이미지는 없습니다.**
- 분할은 호기별로 나누고, 연속 촬영된 이미지(약 60초 이내)는 같은 분할에 넣어야 누수가 없습니다.
