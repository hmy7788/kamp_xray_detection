## 상자 크기와 데이터 계보
- **상자 크기**: 공식 라벨 한 변 중앙값 10px(1·2호기)·13px(3호기). 팀 라벨은 클릭 중심에 같은 크기 네모를 자동 생성
  - 덧붙임: 팀 라벨 박스를 직접 재 보니 1·2호기는 모두 10.0px, 3호기는 약 13.4px 고정이었고, 공식 라벨은 한 변 5~21px로 변동이 있습니다. 그래서 크기별 분석은 공식 라벨로만 의미가 있습니다.
- **데이터 계보**: KAMP 원본 BMP → 중복 제거 → 장비 색상 박스 제거(주변 회색 메움) → 회색조 PNG
