# notebooks — 노트북

| 폴더 | 내용 |
|---|---|
| `shared/` | 팀 공용 노트북 (기존 실습 노트북 2개) |

- 노트북(`.ipynb`)은 JSON이라 병합 충돌이 나면 풀기 어렵습니다. 그래서 **사람별 폴더로 나누고 본인 폴더에서만** 작업합니다.
- **출력(output)을 지우고 커밋**하세요. 출력에 개인 경로나 데이터 이미지가 남을 수 있습니다.
- 정식 실험은 노트북이 아니라 스크립트(`../scripts/`)로 실행합니다.
