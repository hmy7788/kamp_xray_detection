## 01 실험에서 알게 된 것 (보고서 데이터 진단·오류분석 재료)
1. **이물질은 제품 기준 고정 위치에 있다.** 제품은 프레임 안에서 움직이고 기울어지지만 이물질 3개는 항상 어두운 띠 왼쪽 끝에 세로로 있다. 500장에서 라벨 위치와 제품 위치의 세로 상관 0.87~0.95, 편차는 제품 크기의 2~3%. 같은 시편(테스트피스)을 반복 촬영한 데이터라는 뜻이다.
2. **장비가 불량이라고 판정한 사진만 저장된다.** 그래서 정상 사진이 0장이고, 색상 박스는 장비가 그린 판정 표시다. 장비가 놓친 이물질은 데이터에 없으므로 "장비 미탐지 조건" 은 이 데이터로 알 수 없다.
3. **모델은 자리를 외운다.** val 사진에서 이물질을 지운 합성 정상 350장 중 76% 에서 지운 자리를 여전히 찾는다(찾은 상자 334개 전부 지운 자리). 임의 자리를 같은 방식으로 메운 대조 사진은 0% 라 메운 흔적 탓이 아니고, 16px 더 넓게 메워도 62% 다. 이물질이 실제로 있으면 확신도 0.75 이상, 자리만 있으면 0.2~0.7 이라 점도 보지만 자리만으로도 반응한다. 임계값 0.75 에서 합성 정상 오경보 6.9%, 원본 재현율 0.998 로 폭이 매우 좁다.
4. **놓친 7개는 전부 공식 라벨이고 중심은 다 맞췄다.** 팀 라벨이 10px 고정 네모라 모델이 그 크기를 배웠고, 공식 라벨은 6~14px 라 IoU 0.5 에서 떨어진다. 공식 라벨 F1 0.950, 팀 라벨 1.000.
