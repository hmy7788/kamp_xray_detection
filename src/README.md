# src — 모델 코드

| 폴더 | 성격 | 규칙 |
|---|---|---|
| `yolov3/` | **공유** 베이스라인 (수정본 YOLOv3) | 바꾸려면 PR과 팀 확인 |
| `minyeop/` | 개인 (허민엽): Faster R-CNN | 본인만 수정 |
| `yeonchang/` | 개인 (정연창) | 본인만 수정 |
| `chong/` | 개인 (이총) | 본인만 수정 |

- 각자 자기 모델 코드를 자기 폴더에 둡니다. 다른 사람 폴더는 수정하지 않습니다.
- 폴더 이름은 영문(ASCII)만 씁니다. 한글 경로는 이미지 읽기와 인코딩 오류를 일으킵니다.
- 실험 결과는 `../runs/<이름>/`, 탐색용 노트북은 `../notebooks/<이름>/`에 둡니다.
- 협업 규칙은 [../CONTRIBUTING.md](../CONTRIBUTING.md)를 보세요.
