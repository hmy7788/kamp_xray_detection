# 평가 지표 (보고서 표 2-1)

구현: `src/kamp_xray/metrics.py`. 모든 모델이 같은 함수로 채점된다.

| 지표 | 정의 | 선정 이유 |
|---|---|---|
| mAP50 | IoU 0.5 이상을 검출로 보고, 신뢰도 기준을 바꾸어 가며 구한 정밀도-재현율 곡선의 면적 (VOC 전 구간 보간) | 임계값 하나에 의존하지 않고 이물질을 찾는 능력을 비교 |
| mAP50-95 | IoU 0.50~0.95 (0.05 간격) 10개 AP의 평균 | 상자 위치·크기 정확도. 약 10px 객체라 중심 1~2px 차이에도 민감 |
| Precision | 이물질로 판정한 것 중 실제 이물질의 비율 | 오검출 (정상품 재검사 부담) |
| Recall | 실제 이물질 중 검출한 비율 | 미검출 (불량 유출). 검사 장비 특성상 가장 중요 |
| F1 | Precision과 Recall의 조화평균 | 임계값 선정과 모델 비교 |
| FPS (CPU 4스레드) | 1000 / 장당 지연(ms), 배치 1 | GPU 없는 현장 PC에서 실시간 적용 가능성 |

## 규칙

- **매칭**: 이미지별로 신뢰도 내림차순, IoU ≥ 0.5이고 아직 짝이 없는 정답 중 IoU 최대인 것과 1:1 매칭.
- **임계값**: Precision·Recall·F1은 임계값에 따라 달라지므로 val에서 F1이 최대인 신뢰도로 고정하고, test에는 같은 값을 쓴다. test는 한 번만 채점했다.
- **보조 지표** (`eval_report_*.json`)
  - `center_distance.r{1..5}px`: IoU 대신 중심 거리 r px 이내로 매칭한 P/R/F1. 팀 라벨이 고정 크기 상자라 IoU 오류 중 상당수는 크기 차이에서 생기므로, 위치를 맞혔는지 따로 본다.
  - `image_level`: 영상 내 최고 신뢰도가 임계값 이상이면 불합격으로 보는 이미지 단위 판정 (현장 판정 방식, 보고서 4.1절).
  - `by_group`: 라벨 출처(공식/팀), 호기, 해상도, 촬영 월별 P/R/F1과 AP50.
  - `fppi`: 이미지당 오검출 수. `empty_label_images_with_fp`: 이물질 없는 영상 중 오검출이 있는 영상 수.

## 주의

- 팀 라벨(2,032장)은 고정 크기 상자라 IoU 0.5 기준 점수가 쉽게 포화된다. 모델 간 차이는 mAP50-95와 합성 이물질 실험에서 더 잘 드러난다.
- 정상 제품 영상이 데이터에 없으므로 정상품 오검출률은 측정할 수 없다. 빈 라벨 영상(제품이 절반만 찍힌 영상)과 이물질을 지운 영상으로 범위만 추정했다.
