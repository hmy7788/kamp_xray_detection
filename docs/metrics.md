# 성능 지표 정리

X-ray 결함 검출(detection) 모델에 쓸 수 있는 지표를 이 데이터셋 기준으로 정리한 문서.

## 1. 전제: 이 데이터셋의 특성
- 클래스 1개(`defect`), 결함 크기 약 10px (공식 라벨 5~21px)
- **정상(결함 없음) 이미지는 사실상 없음**: 전부 장비 NG 판정 이미지. 예외로 **빈 라벨 105장**(train 59 / val 19 / test 27)이 있으나 제품이 반만 찍혀 테스트피스가 없는 특수한 사진
- 해상도 혼재 (576x444, 352x332, 316x332, 412x332)
- 평가셋: **val 369장(박스 606개), test 396장(박스 663개)** (확정 v2, 촬영 묶음 단위 분할)
- 박스가 작아 중심이 몇 px만 어긋나도 IoU 급락 (10px 박스, 중심 3px 오차 → IoU 약 0.54)
- **라벨 두 종류**: 공식 라벨 500장(박스 1,147개, 실제 크기)과 팀 라벨 2,032장(박스 3,347개, 1·2호기 10px·3호기 약 13px **고정 크기**)
  - 팀 라벨에서는 크기 오차가 사라지고 중심 오차만 남음
  - val 중 공식 59장, test 중 공식 85장 → 공식/팀 라벨을 나눠 평가 가능

## 2. 박스 단위 지표 (핵심)

### 2-1. TP / FP / FN
- TP: 예측 박스가 정답 박스와 IoU 기준 이상 겹침 (기본 IoU 0.5)
- FP: 어떤 정답과도 겹치지 않는 예측 박스 (배경에서 결함이라고 한 것, 같은 결함의 중복 예측)
- FN: 어떤 예측과도 겹치지 않는 정답 박스 (놓침)
- 예측 박스 하나는 정답 하나와만 짝지음 (신뢰도 높은 순서로 매칭)
- **정상 이미지 없이도 계산 가능**
  - 박스 하나하나를 세는 지표이며 이미지 단위 분류가 아님
  - FP는 결함이 있는 이미지의 배경 영역에서도 발생

### 2-2. Precision / Recall / F1
- Precision = TP / (TP + FP) : 예측한 것 중 맞은 비율
- Recall = TP / (TP + FN) : 정답 중 찾은 비율
- F1 = 2PR / (P + R)
- **신뢰도 임계값을 val에서 정해 고정하고 test에 그대로 적용** (test는 1회만 평가)
- 임계값 선택 기준: val에서 F1 최대 또는 "재현율 목표 이상에서 FP 최소"

### 2-3. AP (Average Precision)
- AP@0.5: 신뢰도 임계값을 전 구간 훑어 만든 PR 곡선의 면적
  - 임계값에 덜 민감해 모델 간 비교의 주 지표로 적합
  - 단일 클래스라 mAP = AP
- AP@[.5:.95]: IoU 0.5~0.95 평균 (COCO 방식)
  - 작은 박스에서는 지나치게 가혹하고 변동이 큼 → 참고용
- 계산 방식 명시 필수 (VOC 전 구간 보간 / COCO 101점 보간)

### 2-3. 곡선
- PR 곡선: 임계값별 정밀도-재현율
- F1-임계값 곡선: 운영 임계값 선택 근거
- 임계값별 TP/FP/FN 표

### 2-4. 위치 정확도
- 중심 거리 기준 매칭: 예측 중심이 정답 중심에서 r px 이내면 TP
  - 점 모양의 작은 결함, 고정 크기 박스 라벨에 적합 (시험해 보지 않음)
  - r은 해상도별 박스 크기에 맞춰 설정 (예: 약 5px)
- TP의 중심 오차(px) 평균·분포
- TP의 IoU 분포

## 3. 이미지 단위 지표

### 3-1. 정상 이미지 불필요 (정답이 있는 이미지만 사용)
- 이미지 검출률: 정답이 있는 이미지 중 1개 이상 찾은 비율
- 이미지 완전 검출률: 이미지의 모든 결함을 찾은 비율 (이미지당 결함이 3개인 경우가 많아 의미 있음)
- FPPI (False Positives Per Image): 이미지당 평균 FP 수 (현장 오경보 빈도의 직관적 지표)
- FROC / Miss rate vs FPPI: 허용 FPPI별 재현율 (산업 검사 표준)
- 개수 오차: 이미지별 (예측 개수 - 정답 개수)의 MAE

### 3-2. 정상 이미지 필요 (빈 라벨 105장으로 제한적으로만 가능)
- 이미지 단위 정상/불량 분류의 특이도(Specificity)
- 이미지 단위 FP율 (정상 이미지를 불량으로 판정한 비율)
- ROC-AUC, 이미지 단위 정밀도
- 빈 라벨 105장(test 27장)이 유일한 후보
  - 제품이 반만 찍힌 특수한 사진이라 일반적인 정상 제품 이미지가 아님
  - test 27장뿐이라 변동이 크고 일반화에 한계 → 계산하더라도 "제한적 참고값"으로 표기

## 4. 조건별 분해 (오류분석용)
- 박스별 조건이 `data/conditions.csv`(4,494행)에 준비되어 있고 구간 경계는 `conditions_thresholds.json`에 있음
  - 열: `box_side_px`, `local_contrast`, `ring_mean`(배경 밝기), `edge_dist_norm`, `machine`, `resolution`, `month`, `source`, `labeler`, `size_bin`, `contrast_bin`, `bg_bin`, `edge_dist_bin`
- 같은 지표를 아래 기준으로 나눠 계산
  - 호기, 이미지 해상도, 촬영 월
  - 국소 대비(`contrast_bin`: low/mid/high 3등분), 배경 밝기(`bg_bin`: dark/mid/bright 3등분)
  - **결함 크기 구간별 재현율**
  - 이미지당 결함 개수 (1개 vs 3개), 출처(공식/팀 라벨)
- FN·FP 사례 모음 (이미지 이름, 위치, 신뢰도)
- **조건 열 사용 시 주의**
  - 크기: 팀 라벨은 고정 크기라 `size_bin`(small 2,731 / mid 277 / large 1,486)이 크기보다 호기를 반영 → **크기별 분석은 공식 라벨 박스(1,147개)만 사용**
  - 가장자리: `edge_dist_bin`은 near 8개뿐이라 분석 불가
  - 대비·배경: 3등분이라 각 구간 1,498개로 균형

## 5. 신뢰도와 운영
- 임계값별 Precision/Recall 표
- 운영점 선택: val F1 최대 / 재현율 목표 기준 / 허용 FPPI 기준
- 보정(calibration): reliability diagram, ECE
  - 이전 모델은 신뢰도가 낮게 나와 0.5 이상에서 검출 0개 → 확률 보정 개선 여지

## 6. 불확실성
- 이미지 단위 부트스트랩 신뢰구간 (이전 49장 평가에서는 필수였고, test 396장이 된 지금은 덜 급하지만 모델 간 차이가 작을 때 필요)
  - 연속 촬영본은 서로 닮아 독립 가정이 낙관적 → 한계로 명시
- 여러 시드 평균·표준편차
- 묶음 기준 k-fold 교차검증

## 7. 효율 (현장 활용용)
- 추론 시간 (ms/장), 처리량 (FPS)
- 파라미터 수, 모델 파일 크기
- 학습 시간, GPU 메모리 사용량

## 8. 해석·검증
- Grad-CAM: 모델이 어느 영역을 보고 판단하는지
- 지운 흔적 반응률: 결함이 없는 자리에 표시를 그렸다 지운 이미지에서 모델이 반응하는 비율 (지름길 검증)
- 표시를 지우지 않은 입력과 지운 입력의 성능 비교

## 9. 사용하지 말 것·주의
- YOLOv3 `test.py`의 P/R/F1: 신뢰도 0.1 한 지점 값이라 모델 신뢰도 보정에 따라 크게 변동 (사용 금지, AP는 참고 가능)
- 임계값을 test에서 정하는 것 (누수)
- 정상 이미지가 사실상 없는 상태에서 "오경보율이 낮다"고 일반화 (FP는 결함 이미지 안의 오검출만 측정한 값, 빈 라벨 105장은 특수한 사진)
- 라벨 누락: 모델이 찾은 진짜 결함이 정답에 없으면 FP로 집계되어 FP 과대 계상
- 고정 크기 팀 라벨로 크기 정확도를 논하는 것 (크기는 공식 라벨만 의미 있음)
- 공식/팀 라벨을 섞은 하나의 수치만 보고하는 것 (출처별 분리 보고 권장)
- 지표 정의(IoU 기준, AP 보간 방식, 매칭 규칙)를 모델 간 동일하게 유지

## 10. 권장 보고 세트 (최소)
- AP@0.5
- val에서 고정한 임계값의 Precision / Recall / F1 (TP / FP / FN 병기)
- 이미지 완전 검출률, FPPI
- 결함 크기·호기·해상도별 재현율
- 부트스트랩 신뢰구간
- 추론 시간

## 11. 평가 항목 대응
- 모델 개발·비교 (40점): AP@0.5, P/R/F1, TP/FP/FN, 신뢰구간
- 영향요인·오류분석 (15점): 조건별 분해, FN·FP 사례, Grad-CAM
- 현장 활용 (10점): FPPI, 운영 임계값, 추론 시간·모델 크기
- 창의성 (10점): 확률 보정(ECE), 지운 흔적 반응률 검증
- 코드·재현성 (10점): 지표 계산 코드·매칭 규칙·임계값 선택 절차의 자동화

## 12. 참고: 이전 시도에서 확인한 사실 (삭제된 결과, 새 결과와 직접 비교 금지)
- 표시를 지운 n500 기준 test F1: YOLOv3-tiny 0.940, YOLOv3-SPP 0.966 (정답 박스 116개)
- 두 모델 차이의 부트스트랩 95% 구간 +0.003 ~ +0.054 → 우열 확정 불가
- 두 모델 모두 신뢰도가 낮아 임계값 0.5에서 F1 0
- 이미지 검출률 0.96~1.00 (SPP 1.00, tiny 0.96), 이미지 완전 검출률 0.82~0.92 (val·test, 모델별)
