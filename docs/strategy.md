# 우승 전략 검토 (2026-09-30 기준)

"무조건 1등"은 보장할 수 없다(서면평가 위원 5인, 경쟁팀 수준은 미지). 평가표에서 점수를 잃을 곳을 막고 차별화 지점에 집중하는 방향이다. 배점과 현재 상태는 [evaluation.md](evaluation.md).

## 가장 큰 리스크

1. **공식 데이터·제출 형식 미확인**: 현재 라벨된 데이터는 고유 400장. 공지는 약 1.8GB 데이터와 "테스트데이터 예측결과 파일 필수"를 언급하나 공식 데이터의 구성, 테스트 데이터 유무, 예측 파일 형식, 결과 보고서 양식을 모른다. KAMP 로그인이 필요해 사용자가 받아야 한다.
2. **평가표 해석**: "이상 확률 예측", "변수", "공정조건" 등 표형 데이터 표현. 영상 과제에는 이미지 단위 분류 F1과 bbox 단위 P/R/F1을 함께 제시하는 것이 안전하다.
